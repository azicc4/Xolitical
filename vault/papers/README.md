# Papers

One note per scientific paper or primary source. PDFs may be stored here directly (small ones) or linked by URL/DOI.

Suggested frontmatter:

```yaml
---
title: ""
authors: []
year:
doi: ""
url: ""
added_by: ""
tags: []
---
```

Media notes reference papers through their `papers` property (wiki-links), so a paper's backlinks pane shows every media item citing it.
