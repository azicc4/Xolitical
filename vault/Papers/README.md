# Papers

One note per scientific paper or primary source. Small PDFs can be stored here directly. Otherwise link them by URL or DOI.

Suggested frontmatter:

```yaml
---
title: ""
authors: []
year:
doi: ""
url: ""
added_by: ""
tags: []
---
```

Link papers from an event note **below** its `%% xolitical:end %%` line, for example `Related: [[Smith 2021 - Inflation expectations]]`. The paper's backlinks pane will then list every event that cites it.
