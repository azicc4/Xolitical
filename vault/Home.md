# Xolitical

A collaborative archive of political media (screenshots, images, videos and articles from Twitter/X, Instagram, YouTube and Substack), grouped into **named events** and filed under **categories › subcategories**.

## Browse

Open [[Xolitical.base]] for every view: **Gallery** · **Events** · **Categories** · **Needs review** · **Papers**.

![[Xolitical.base#Gallery]]

## How this vault is built

- **Events** (`Events/<year>/`): one note per event. Its category links sit at the top, followed by every media file paired into the event, each with its own note and source link.
- **Categories** (`Categories/`): one note per category and subcategory. Each one lists every event that links to it.
- **Papers** (`Papers/`): scientific papers and primary sources, linked from events.
- Notes in `Events/` and `Categories/` are generated by the Xolitical viewer (`tools/viewer/`) from the index in `.xolitical/`. Text you write **below** the `%% xolitical:end %%` line is preserved; everything above it is regenerated.
- Media files live in `_media/`. That folder is local to each machine and never committed.
